# SentinelAI – AI Powered Cloud & Web Security Copilot

SentinelAI is an enterprise-grade cybersecurity platform that leverages AI to scan web applications, APIs, and cloud infrastructure for vulnerabilities. It provides real-time threat intelligence, risk scoring, and AI-generated remediation suggestions.

## 🚀 Features

- **🌐 Website Security Scanner**: Audit URLs for missing security headers, weak CORS policies, and server info leakage.
- **🧠 AI Security Analyzer**: Get deep insights and remediation code snippets powered by Google Gemini AI.
- **📊 Operations Dashboard**: Real-time monitoring of threat activity, scan history, and overall security posture.
- **🛡️ Cloud Security Module**: Simulated detection of public buckets, weak IAM roles, and open ports.
- **🎯 Interactive Attack Lab**: Educational simulations of SQL Injection, XSS, and CSRF for security awareness.
- **📄 Security Reports**: Archive and review detailed vulnerability reports.
- **🔐 Secure Authentication**: Integrated Firebase Auth with Google login.

## 🛠️ Tech Stack

- **Frontend**: React (Vite), TypeScript, Tailwind CSS, Framer Motion, ShadCN UI.
- **Backend**: Node.js (Express) – used for the scanning engine.
- **Database**: Firebase Firestore.
- **AI**: Google Gemini Pro (via @google/genai SDK).
- **Icons**: Lucide React.
- **Charts**: Recharts.

## ⚙️ Setup & Installation

1. **Environment Variables**:
   Ensure `.env` contains:
   - `GEMINI_API_KEY`: Your Google AI Studio API Key.
   - `VITE_FIREBASE_CONFIG`: Handled automatically in this environment via `firebase-applet-config.json`.

2. **Run Development Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   npm start
   ```

## 🛡️ Security Best Practices

SentinelAI is designed with defense-in-depth:
- **Least Privilege**: Firestore rules strictly enforce user-owned data access.
- **Input Sanitization**: All scan targets are validated and handled securely on the backend.
- **AI-Driven Remediation**: Suggestions are generated by Gemini Pro for high-accuracy security advice.
